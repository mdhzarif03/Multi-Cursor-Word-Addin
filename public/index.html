Multi-Cursor for Word

Edit many places in a Word document at once: select every match, add cursors, and type, format or transform them together.

Download add-in file

Free. Works in Word on the web, Windows and Mac. Reads and edits only the open document, and sends nothing anywhere.

Install

Word on the web (easiest, about 30 seconds)

  1. Download the add-in file above.
  2. Open a document at word.office.com.
  3. Go to Home > Add-ins > More Add-ins (or Insert > Add-ins), choose Upload My Add-in, and select the file.
  4. Click Multi-Cursor on the Home tab.

Word on Windows

  1. Download the add-in file and save it in a new folder, e.g. C:\WordAddins.
  2. Right-click the folder, Properties > Sharing > Share, and copy the network path (\\PC-NAME\WordAddins).
  3. In Word: File > Options > Trust Center > Trust Center Settings > Trusted Add-in Catalogs. Paste the path, click Add catalog, tick Show in Menu, then restart Word.
  4. Insert > My Add-ins > Shared Folder, select Multi-Cursor, Add.

Word on Mac

  1. Download the add-in file.
  2. Copy it to ~/Library/Containers/com.microsoft.Word/Data/Documents/wef/ (create the wef folder if missing).
  3. Restart Word, then Insert > My Add-ins and pick Multi-Cursor.

What it does

Select all matchesFind text and select every occurrence (match case, whole word, wildcards, within selection).
Add cursorsStore several positions, or one cursor at the start or end of every line in a selection.
Type at all cursorsReplace or insert at every cursor at once. {n} inserts a counter (1, 2, 3...).
TransformUPPER, lower, Title Case, bold, italic, underline, delete.

Word's add-in API cannot show real blinking carets, so cursors are managed from the task pane. Cursors are cleared when the pane is closed.
